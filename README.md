راهنمای اجرا (ویندوز - PowerShell)

پیش‌نیازها

- Python 3.8+ نصب شده باشد.

مراحل سریع:

1. در پوشه پروژه یک virtual environment بسازید و فعال کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. وابستگی‌ها را نصب کنید:

```powershell
python -m pip install -r requirements.txt
```

3. برنامه را اجرا کنید:

```powershell
python app.py
```

بعد از اجرا، به آدرس http://localhost:5000 در مرورگر بروید.

توضیحات و نکات ایمنی:

- فایل‌های فرانت‌اند به مسیرهای `templates/` و `static/` منتقل شده‌اند تا با Flask کار کنند.
- فایل‌های `dest-numbers.txt` و `processed.txt` در همان پوشه پروژه ساخته می‌شوند و برای ورود/خروج شماره‌ها استفاده می‌شوند.
- لطفاً مقادیر پیش‌فرض نام کاربری/رمز عبور را در رابط کاربری پاک کنید و اطلاعات واقعی را وارد نکنید.

در صورت نیاز می‌تونم کمک کنم برنامه را به عنوان سرویس ویندوز یا سرویس دِمون اجرا کنم، یا TLS/HTTPS اضافه کنم.
